Entry for the [make.fun competition "The joke about the demo"](https://make.fun/c/the-joke-about-the-demo-20261123-0112).

`main.ts` (Node 22) writes one one-line joke about working beside an AI coding agent to `/output/entry.txt`:

> The demo crashed live, so my agent blamed a package that doesn't exist — and then offered to install it.

Run it with `node main.ts`. The entry is 104 characters, one line, no network.
